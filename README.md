updated # Adwaith S Rajeev - Portfolio

A modern, minimalist, fully responsive Full Stack MERN Developer portfolio built with React, Tailwind CSS, and Framer Motion.

## Features

- 🎨 Terminal/CLI-inspired design with neon green accents
- 📱 Fully responsive across all devices
- ✨ Smooth animations using Framer Motion
- 🚀 Built with React functional components and hooks
- 🎯 Production-ready and recruiter-friendly

## Tech Stack

- React 18
- Tailwind CSS
- Framer Motion
- Vite

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Sections

1. **Hero Section** - Terminal-style layout with typing animation and profile image
2. **Profile Summary** - Professional summary with fade-in animation
3. **Skills Section** - MERN stack icons with hover animations
4. **About Section** - Card-style layout with slide-in animation
5. **Education Section** - Route/roadmap style with sequential animations
6. **Projects Section** - Responsive grid with hover effects
7. **Contact Section** - Minimal layout with neon hover effects
8. **API Animation** - Background terminal-style API call animations

## Design

- Dark background (#0a0a0a) with subtle gradients
- Neon green (#00ff9c) for highlights and accents
- Monospace fonts (JetBrains Mono)
- Minimalist UI with smooth, subtle animations
